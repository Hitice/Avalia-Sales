# 0002. .NET 10 LTS

- Situação - Aceita
- Data - 21/10/2026

## Contexto

A stack de referência pede .NET 8, que sai de suporte em 10/11/2026.

## Opções

- .NET 8 LTS
- .NET 10 LTS

## Decisão

.NET 10 LTS. O código é o mesmo modelo de ASP.NET Core, EF Core e Worker Service; a diferença que aparece é o OpenAPI nativo, que no .NET 8 seria o Swashbuckle.

## Consequências

- Suporte até 11/2028.
- Versão centralizada em `Directory.Build.props` e `Directory.Packages.props`.
